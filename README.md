# Mapa-interactivo
Proyecto educativo desarrollado en Python por estudiantes de 6.º año, en el espacio curricular Algoritmos y Lenguajes de Programación.

El objetivo es crear un mapa interactivo de La Ribera que permita identificar lugares de interés y brindar información útil a la comunidad, utilizando Folium, SQLite y Flask.

Durante el desarrollo se trabajará con herramientas de Inteligencia Artificial como apoyo para investigar, resolver problemas y aprender a programar.

Programar también es crear soluciones para los demás, poniendo en práctica valores como la solidaridad, la responsabilidad y el compromiso.
